# FishIdle HUD

[![一键安装](https://img.shields.io/badge/%E4%B8%80%E9%94%AE%E5%AE%89%E8%A3%85-FishIdle%20HUD-2ea44f?style=flat-square)](https://raw.githubusercontent.com/julismme/fishidle-hud/main/fishidle-hud.user.js)

[fishidle.com](https://fishidle.com) 的辅助面板，Tampermonkey（油猴）脚本，单文件。它在游戏页面上叠加一块悬浮面板和几个辅助工具，只在 `https://fishidle.com/game/*` 生效。

## 安装

1. 在浏览器里装好 [Tampermonkey](https://www.tampermonkey.net/)。
2. 点上面的“一键安装”按钮，Tampermonkey 会弹出安装确认，点“安装”。
3. 打开游戏，右上角出现面板。

一键安装打不开时，可以试备用链接（jsDelivr 同步的同一份文件）：<https://cdn.jsdelivr.net/gh/julismme/fishidle-hud@main/fishidle-hud.user.js>。或者打开仓库里的 `fishidle-hud.user.js`，点 Raw，全选复制，在 Tampermonkey 里新建脚本并粘贴保存。

安装后 Tampermonkey 会定期检查更新，检查周期可以在它的设置里调整；也可以在它的管理面板里手动检查。

临时试用：进入游戏后按 F12，在 Console 里粘贴脚本全文并回车，刷新页面即失效。这种方式下保持活跃不生效。

## 功能

| 模块 | 做什么 | 入口 |
|---|---|---|
| 悬浮面板 | 当前活动、队列各项的完成时间与合计，技能升级预估；可拖拽、可收起，位置自动记忆 | 页面右上角 |
| 置顶小窗 | 把面板画成视频画中画窗口：无网址栏、始终置顶，浏览器最小化后仍可见；只能看，不能操作。需要 Chrome / Edge 等支持视频画中画的浏览器 | 面板 📌 |
| 战斗监控 | 战斗中显示分均金币（掉落 ÷ 战斗时间，只统计单场，重开后重新统计）和本场掉落；喝过的药剂显示剩余数量与耗尽时间，低于阈值标黄；组队战斗同样生效 | 战斗时自动显示 |
| 死亡告警 | 红色闪烁横幅、标签页标题告警；单人战斗和组队战斗里自己倒下时都生效 | 自动触发 |
| 保持活跃 | 标签页在后台时，服务器照常结算战斗和队列 | 面板 ⚡ |
| 对话框增强 | 在“开始制造 / 采集 / 炼金”对话框里显示升级所需次数和预计时间 | 打开对话框时自动注入 |
| 收藏 | 记住配方或采集资源及其次数，一键开始或加入队列，最多 12 条 | 左侧栏 ⭐ 收藏 |
| 发育计算器 | 战士、坦克、冰、火法、牧师、猎人、盗贼七条装备线的物料缺口和制造耗时（T1–T7），可按缺口一键加入收藏 | 左侧栏 📊 发育 |
| 渔舍计算器 | 渔舍页每个材料显示“还差”多少（需求 − 已填入 − 背包） | 渔舍页自动注入 |
| jojo-plugin 页签 | 在游戏设置页里按模块开关悬浮面板、发育计算器、收藏夹、对话框增强、渔舍计算器 | 游戏设置 → jojo-plugin |

## 使用前请了解

- 脚本不向任何第三方服务器发送数据。面板数据只读；渔舍计算器会通过游戏自己的连接读取一次渔舍状态（与打开渔舍页时游戏自己的请求相同）。
- 会触发服务器动作的只有**收藏的开始 / 入队**。它通过游戏自己的接口发起，参数与点击官方按钮相同。
- **保持活跃**会让游戏在后台标签页继续向服务器上报“可见”。它改变了游戏的默认行为，是否开启请自行评估。
- 脚本依赖游戏前端的内部结构，游戏更新后可能失效。

## 悬浮面板

| 区 | 内容 |
|---|---|
| 当前 | 活动名、预计完成时间、剩余次数；战斗时显示地图（组队显示组队地图）与击杀数，以及分均金币、本场掉落和喝过的药剂余量与耗尽时间 |
| 队列 | 每项的预计耗时和合计；有算不出的项时合计带 ≥，无限项记作 ∞；战斗中标题变为“队列（战斗结束后执行）” |
| 升级预估 | 采集和战斗技能按最近 5 分钟的经验增速估算升级时间，只显示与当前活动或当前战斗对应的技能 |
| 生产预估 | 制造时改为精确计算：升级所需次数、单次时间、升级时间、每次材料、背包剩余、实际剩余次数、料尽时间 |

制造活动的次数按背包材料计算：可做次数取各配料“库存 ÷ 单耗”的最小值，再与计划次数取小。材料不够时显示“缺料（可做 / 计划）”，缺料项不计入队列合计。强化和炼金活动不计算完成时间。

## 战斗监控

- **分均金币**：只统计单场，掉落 ÷ 战斗时间。战斗重开（死亡后自动复活再战、手动再来、队列下一场）就是新一局，重新开始统计。单人战斗直接用游戏记的本场掉落与这一局的时长（`combatState.lootGold / startedAt`），刷新页面、市场买卖都不会算错；组队战斗按自己钱包的增加累计，买东西的支出不算（战斗期间的卖出所得也会计入）。这一局不满 30 秒显示“统计中…”。
- **金币统计的连续性**：单人的掉落和时长本来就来自游戏状态，页面重载后自动对上，不会串成别的局的数据；组队的时长与掉落断点存在当前标签页的 `sessionStorage` 里，同一局战斗在页面重载（如刷新页面）后接着算。页面被浏览器挂起超过 2 分钟的时间不计入战斗时长；标签页在后台且没开保持活跃时服务器不结算，这段时间同样不计。
- **药剂**：战斗中背包里药水（物品类别以 `Potion` 开头）的数量每少 1 记一次使用，这一场喝过的药水各占一行，显示剩余数量和按最近 8 次使用的平均间隔推算的耗尽时间；喝出速率之前该行不显示。耗尽时间低于设置页里的药水告警阈值（默认 10 分钟）标黄，用完标红。这一场只喝过一次时按本地保存的历史间隔估算并标“（估）”。
- **组队战斗**：组队战斗的状态在 `party` store。面板按当前角色在 `players` 里找到自己那一项，战斗行显示“组队·地图（击杀数或波次）”，分均金币、药剂、升级预估和死亡告警都与单人战斗相同，队列同样标注“战斗结束后执行”。队友倒下不告警。

## 保持活跃 ⚡

游戏在标签页切到后台时会让服务器暂停战斗和队列结算。开启后，脚本让游戏在后台时仍向服务器上报“前台”，结算照常。开关状态保存在本地，开或关都会让游戏立即重新上报一次。

## 收藏与对话框增强

- 打开“开始制造 / 采集 / 炼金”对话框时，在“添加到队列”按钮上方插入两行读数（升级所需次数、升级预计时间）和一个 **⭐ 收藏此项** 按钮，后者记住对话框里当前选的次数，∞ 也能记住。
- 采集的单次经验和间隔按游戏公式直接算出；制造职业的经验来自游戏的玩家状态和生产 tick，并缓存在本地。两者一般都不需要先做一次。炼金没有客户端数据，只显示已采样到的经验。
- 点左侧栏“交易行”上方的 **⭐ 收藏** 打开收藏页。每张卡片列出产出、经验和单次耗时；制造卡还列出材料和按背包算出的可制作次数，采集卡在技能等级不足时置灰提示。**▶ 开始** 立即执行，**＋ 入队** 追加到队列，**✕** 移除。
- 点左侧栏任意原生条目会关闭收藏页。

## 发育计算器 📊

- 顶部可切换职业：战士、坦克、冰、火法、牧师、猎人、盗贼，选择保存在本地。每条装备线是武器加五件护甲，件名取自游戏的配方目录。
- 各职业的装备线：战士是巨剑 + 板甲，坦克是战剑 + 盾 + 板甲，冰和火法是魔杖 + 魔典 + 布甲，牧师是法杖 + 布甲，猎人是弓 + 皮甲，盗贼是匕首 ×2 + 皮甲。
- 目标是所选职业的 T7 套装。按 T1 到 T7 分块展示，需求只按 T7 终品计算，T1–T6 各阶件作为升级材料出现在链路里。
- 各阶的套装件显示它在整套里的需 / 有 / 缺、职业技能门槛和制造耗时。库存里已有的自动抵扣，穿戴中的装备也算作“有”。
- 点条目行展开材料树：每一行是做一件上级物品的单品消耗（×N），同一种材料在不同装备下各算各的，不做合计。
- 底部的**缺口合计**可以展开，按物料列出还缺多少，并可切换统计做到哪一阶还缺多少（T1–T7）。没选过时自动取第一个还没凑齐的阶，选择保存在本地。顶部汇总制造总耗时。
- 点块头展开或折叠整块。材料树里的 **⭐+N** 按 T7 整套的缺口把该配方加入收藏，缺口合计里的 **⭐+N** 按所选阶的缺口。

## 设置页的 jojo-plugin 页签

游戏设置页的账号、游戏、隐私三个页签下面多了一个 **jojo-plugin** 页签，里面是五个开关和一个数值项。默认全部开启，改动立即生效，并保存在本地。

| 开关 | 控制什么 |
|---|---|
| 悬浮面板 | 右上角的悬浮面板和置顶小窗 |
| 发育计算器 | 左侧栏的“发育”入口 |
| 收藏夹 | 左侧栏的“收藏”入口，以及对话框和计算器里的收藏按钮 |
| 对话框增强 | “开始制造 / 采集 / 炼金”对话框里的升级次数和预计时间 |
| 渔舍计算器 | 渔舍页每个材料的差额显示 |
| 药水告警阈值（分钟） | 战斗中药水的耗尽时间低于它时在面板里标黄，0 表示不提醒；默认 10 |

关掉悬浮面板后，死亡告警的横幅随面板一起消失，标签页标题告警仍然有效。保持活跃不受影响，仍按原来的开关状态运行；它的开关只在悬浮面板头部，面板关掉后就改不了。

## 没有数据的时候

| 现象 | 原因 |
|---|---|
| 采样中… | 升级速率需要至少两个经验变化点，且跨度不少于 6 秒 |
| 本次会话未生产过该职业 | 该制造职业本地没有缓存，本次也没收到过经验数据 |
| 预计完成为 — | 强化、炼金活动和战斗队列项不计算完成时间 |
| 分均金币显示“统计中…” | 脚本盯上这一局还不满 30 秒：刚开打、战斗重开，或刷新页面重新接手 |
| 分均金币显示 0/分 | 这段时间钱包没有增加：角色在等复活，或刚买过东西 |
| 某种药水没有出现在药剂行里 | 这一场它还没喝出速率（只喝过一次且本地没有它的历史间隔），显示出来也只是“采样中” |
| 状态行出现 ⏸ 或 ⚠ | 页面在后台，或与服务器的连接异常 |
| 切换角色后数据重新预热 | 切换角色会让脚本卸载，回到游戏后重新加载 |

## 本地数据

所有状态都保存在浏览器的 `localStorage`，键名前缀为 `fishidle-hud.`：

| 键 | 内容 |
|---|---|
| `pos`、`collapsed` | 面板位置、收起状态 |
| `keepalive` | ⚡ 的开关状态 |
| `calcClass` | 发育计算器当前选中的职业 |
| `calcTier` | 缺口合计统计到哪一阶 |
| `modules` | 设置页 jojo-plugin 页签里四个开关的状态 |
| `craftXp` | 各制造职业和炼金的经验快照 |
| `gatherXp` | 各采集资源的经验与间隔采样 |
| `favorites` | 收藏列表：`kind`、`id`、`prof`、`name`、`count`，`count` 为 0 表示 ∞ |
| `potionLow` | 药水告警阈值（分钟） |

金币统计的断点存在当前标签页的 `sessionStorage`（键 `fishidle-hud.combatRun`），关闭标签页即清掉。

想清空设置，在游戏页面的控制台执行下面这行后刷新：

```js
Object.keys(localStorage).filter((k) => k.startsWith("fishidle-hud.")).forEach((k) => localStorage.removeItem(k));
```

## 已知限制

- 对话框增强靠中文文案定位，游戏界面语言不是中文时不生效。
- 发育计算器只覆盖 T1–T7。冰和火法在 T1–T7 共用同一条装备线，两页内容相同。战士、坦克按剑计算（锤、斧的配料相同），猎人按弓计算（弩的配料不同）。
